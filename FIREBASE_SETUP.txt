BUNKIT: GOOGLE SIGN-IN + SYNC SETUP (free, about 10 minutes)

1. Go to console.firebase.google.com and sign in with your Google account.
   Click "Create a project", name it (e.g. bunkit), turn OFF Google Analytics, Create.

2. Build > Authentication > Get started > Sign-in method > Google > Enable.
   Choose a support email, then Save.

3. Authentication > Settings > Authorized domains > Add domain.
   Add ONLY the domain, without https:// and without the repo name.
   Example:  yourname.github.io

4. Build > Firestore Database > Create database.
   Choose production mode and any nearby region (e.g. asia-south1 for India).
   Then open the "Rules" tab, replace everything with the text below, and click Publish:

   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }

   (This lets each person read and write only their own data.)

5. Click the gear icon (Project settings) > General > scroll to "Your apps" > click the Web icon </>.
   Register the app (any nickname, skip Firebase Hosting). Copy the firebaseConfig values.

6. Open index.html in GitHub (pencil icon) and find this line near the top of the script:

   const FB={apiKey:"",authDomain:"",projectId:"",appId:""};

   Paste your values between the quotes, for example:

   const FB={apiKey:"AIza...",authDomain:"bunkit-1234.firebaseapp.com",projectId:"bunkit-1234",appId:"1:123:web:abc"};

   (These values are not secret. The Firestore rules in step 4 protect the data.)

7. Commit the change. Wait a minute, refresh the site, and open Subjects:
   you should see "Continue with Google".

If sign-in says "unauthorized-domain", step 3 is missing or has the wrong domain.


ANALYTICS (free and optional): see how many people use the app
-----------------------------------------------------------------
Nothing is collected until you finish steps 1 to 3 below.

1. Firebase console > Project settings (gear icon) > Integrations > Google Analytics > Enable.
   Pick or create a Google Analytics account and keep the defaults. (Menu names may look slightly
   different, but it is always under Project settings in your Firebase project.)

2. Project settings > General > Your apps > your web app. You will now see a measurementId
   that looks like G-XXXXXXXXXX. Copy it.

3. In index.html, find the FB line near the top of the script and paste it into the last field:

   const FB={apiKey:"...",authDomain:"...",projectId:"...",appId:"...",measurementId:"G-XXXXXXXXXX"};

   Commit, wait a minute, then open your site once.

WHERE TO LOOK
- Firebase console > Analytics > Dashboard, or analytics.google.com. "Realtime" shows activity
  within a minute. Most other reports fill in within about 24 hours.
- Users, new vs returning, retention, countries and cities, phone/OS/browser: built in.
- Custom events this app sends:
    app_open          (display = "installed" for home-screen app users, "browser" for web visitors)
    pwa_install       (someone added the app to their home screen)
    onboard_complete  (finished the welcome pop-up)
    tab_view          (tab = today / fore / reg / subj / account)
    mark              (kind = P attended, A bunked, C cancelled, U undone)
    subjects_added    (count)
    login             (signed in with Google)
    share             (method = native / copy / whatsapp / telegram, from the footer share button)
- Firebase console > Authentication > Users lists everyone who signed in with Google.

PRIVACY
- The app never sends names, subject names, emails or attendance numbers to analytics.
- People can switch it off in the Account tab ("Share anonymous usage stats").
  Browsers set to Do Not Track are skipped automatically.
- Good practice: mention in your README that the app collects anonymous usage statistics.
